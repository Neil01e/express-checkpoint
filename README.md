☣️ BIOHAZARD // GLOBAL INTELLIGENCE NETWORK

A Resident Evil themed Express.js application featuring a classified operative database, complete incident timeline, and evidence locker. Access is restricted to working hours (Monday-Friday, 9AM-5PM) with a lockdown countdown timer. Built with Node.js, Express, and EJS, featuring 16 operatives with their respective agency affiliations, custom middleware for time-based access, and a fully responsive terminal-inspired UI.
